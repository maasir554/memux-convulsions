# MEMUX

> Monorepo for **MEMUX** by team **convulsions** — built for the **AMD Slingshot Hackathon**.

## Theme

**Future of Work & Productivity** — reimagining everyday workflows for students, researchers, and early professionals.

## About

MEMUX rethinks the everyday tools that students, researchers, and early professionals rely on, removing friction from the workflows they repeat every day so they can focus on the work that matters.
